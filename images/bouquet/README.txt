Bouquet assets
==============

The main bouquet uses individual flower assets from /clean/ when available.
The /clean/ PNGs have the baked checkerboard background removed.

Files:
- rose.png
- tulip.png
- peony.png
- hydrangea.png
- greenery.png

The React component falls back to the vector flower drawing for daisy,
baby's breath, blossom, and any missing image.

If you replace a flower image, use a transparent PNG/WebP with no background.
